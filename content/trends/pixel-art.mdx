## Tarihsel Bağlam

Pixel art, dijital sanatın en köklü formlarından biridir. 1970'lerin sonu ve 1980'lerin başında, erken video oyun konsolları ve kişisel bilgisayarların sınırlı grafik kapasitesi nedeniyle zorunluluktan doğdu. Atari 2600, Nintendo Entertainment System (NES), Commodore 64 ve Sega Genesis gibi sistemler, yalnızca birkaç renk ve belirli bir çözünürlükle çalışabiliyordu; bu kısıtlamalar, piksel sanatın kendine özgü estetik kimliğini oluşturdu.

Shigeru Miyamoto'nun tasarladığı Mario ve Zelda karakterleri, Konami'nin Castlevania ve Metal Gear serileri ve SNK'nın Neo Geo oyunları pixel art'ın en etkileyici örnekleri arasında yer alır. Sanatçılar, her pikseli tek tek yerleştirerek, renk geçişlerini "dithering" tekniğiyle simüle ederek ve sınırlı palet içinde mükemmellik arayarak benzersiz eserler yarattılar.

2010'lardan itibaren pixel art, indie oyun devriminin lokomotifi haline geldi: Minecraft, Terraria, Celeste, Stardew Valley ve Undertale bu sanat formunu modern oyunculara yeniden tanıttı. Günümüzde pixel art, oyunların ötesinde illüstrasyon, animasyon, marka kimliği ve UI tasarımında bilinçli bir estetik tercih olarak kullanılmaktadır.

## Temel Özellikler

### 1. Sınırlı Renk Paleti

Pixel art'ın temel kısıtlaması ve aynı zamanda estetik gücü, sınırlı renk paletinden gelir. Geleneksel 8-bit sistemler yalnızca 16-64 renk desteklerken, sanatçılar bu kısıtlama içinde olağanüstü detaylar yarattı. Günümüz pixel art'ında da bu kısıtlama bilinçli olarak korunur: genellikle 4-32 renk kullanılır ve her renk seçimi kritik önem taşır.

### 2. CSS Box-Shadow Piksel Tekniği

Web'de pixel art oluşturmanın en güçlü yöntemi, CSS `box-shadow` özelliğinin birden fazla değeriyle tek bir `div` veya `span` elementinden tüm piksel karakterini üretmektir. Her piksel, `x_offset y_offset 0 renk` formatındaki bir gölge değeriyle tanımlanır. Bu teknik, HTML etiket sayısını minimumda tutarken karmaşık karakterler oluşturmayı mümkün kılar.

### 3. Görüntü Pikselleştirmesi

Pixel art görüntülerin ölçeklendirilirken bulanıklaşmaması için CSS `image-rendering: pixelated` (Chromium) ve `image-rendering: crisp-edges` (Firefox) özellikleri kullanılır. Bu özellikler, tarayıcının görüntüyü ölçeklendirirken interpolasyon uygulamasını engeller ve her pikselin net kenarlıklarla korunmasını sağlar.

### 4. Grid Tabanlı Tasarım Sistemi

Pixel art, sıkı bir ızgara disiplini gerektirir: her element 8, 16 veya 32 piksellik grid'e hizalanır. Web tasarımında bu prensip, `8px` katlarında boşluklar, piksel mükemmelliğinde kenarlıklar ve keskin olmayan hiçbir elementin kullanılmaması biçiminde yansıtılır.

## Tailwind CSS Kod Örneği

Aşağıdaki örnek, CSS `box-shadow` tekniğiyle basit bir piksel karakter ve piksel buton bileşenini oluşturur:

```tsx
// CSS box-shadow ile piksel karakter
export function PixelCharacter() {
  // Her piksel: "x y blur renk" — blur her zaman 0
  // 1 birim = 8px grid
  const px = (x: number, y: number, color: string) =>
    `${x * 8}px ${y * 8}px 0 ${color}`;

  // Basit smiley face piksel deseni
  const pixels = [
    // Yüz
    px(1, 0, "#f5c518"), px(2, 0, "#f5c518"), px(3, 0, "#f5c518"),
    px(0, 1, "#f5c518"), px(1, 1, "#f5c518"), px(2, 1, "#f5c518"),
    px(3, 1, "#f5c518"), px(4, 1, "#f5c518"),
    // Gözler
    px(1, 2, "#1a1a1a"), px(3, 2, "#1a1a1a"),
    // Gülümseme
    px(1, 3, "#1a1a1a"), px(2, 3, "#f5c518"), px(3, 3, "#1a1a1a"),
  ].join(", ");

  return (
    <div className="p-8 bg-gray-900 rounded-xl flex flex-col items-center gap-6">
      {/* Piksel karakter — tek div, tüm pikseller box-shadow ile */}
      <div
        style={{
          width: "8px",
          height: "8px",
          boxShadow: pixels,
          imageRendering: "pixelated",
          marginBottom: "32px", // karakter yüksekliği kadar boşluk
        }}
      />

      {/* Piksel sanat butonu */}
      <button
        className="font-mono text-sm uppercase tracking-widest px-4 py-2"
        style={{
          background: "#e83b3b",
          color: "#ffffff",
          imageRendering: "pixelated",
          // Pixel-perfect kenarlık: sadece düz renkler, gölge yok
          outline: "3px solid #000",
          outlineOffset: "-3px",
          boxShadow: "4px 4px 0 #000",
          // Active durumda gölge kayar → basma hissi
        }}
      >
        START GAME
      </button>

      {/* HP çubuğu — piksel blokları */}
      <div className="flex gap-1">
        {Array.from({ length: 8 }).map((_, i) => (
          <div
            key={i}
            className="w-4 h-4"
            style={{
              background: i < 5 ? "#3cb34a" : "#333",
              outline: "2px solid #000",
              imageRendering: "pixelated",
            }}
          />
        ))}
      </div>
    </div>
  );
}
```

Bu örnekte `box-shadow` zinciri ile piksel karakter oluşturma, `imageRendering: pixelated` ile keskin ölçekleme ve `outline` ile pixel-perfect kenarlıklar gösterilmektedir. Tailwind'in `gap-1` ve `w-4 h-4` sınıfları grid disiplinini destekler.

## AI Prompt

Bu tasarım stilini yapay zekayla uygulamak için aşağıdaki prompt'u kopyalayın:

```text
Design a [game/retro product/nostalgic interface] in Pixel Art style.

Pixel art is the oldest form of digital graphic design — born from hardware limitations that became aesthetic choices. Modern pixel art keeps those constraints by choice: every pixel is a deliberate decision, nothing is anti-aliased, and the grid is always visible.

The discipline: snap every element to a consistent pixel grid (typically 8px or 16px). This grid must be respected absolutely — no sub-pixel positioning, no fractional values, no anti-aliasing. The result is an image that looks equally sharp whether viewed at native size or scaled up by an integer factor.

Color is rationed: traditional pixel art uses 4, 8, or 16 colors maximum. The constraint forces creative economy — every color must earn its place, and color transitions are handled through dithering (alternating pixels) rather than gradients.

Characters follow simple proportion rules: the head is approximately the same width as the body for classic RPG sprites.

Design this for my [game/product]. Include at least one pixel character sprite, a background scene, and a UI element (health bar, score display, etc.). Keep the palette to [number] colors maximum.
```
