## AI Prompt

Bu tasarım stilini yapay zekayla uygulamak için aşağıdaki prompt'u kopyalayın:

```text
Design a [product hero section/feature page/loading screen] incorporating 3D Illustration UI elements.

3D illustration UI uses volumetric, three-dimensional visual elements — created with tools like Spline, Blender, or Three.js — integrated into a flat 2D interface. The 3D element creates depth, visual weight, and a premium feeling that flat illustration cannot match.

The approach: one central 3D object (your product, an icon representing a feature, an abstract form representing your brand value) sits as the hero visual. The surrounding UI (text, navigation, CTAs) remains flat and minimal — this contrast between 3D and flat is the design's energy.

The 3D object needs thoughtful lighting: a key light from above-left for form, a fill light from below-right for softness, an ambient light for overall luminosity. Soft shadows ground the object in the space. The shadow should match the background color (colored shadow, not gray).

The style can range: cartoon-like low-poly with flat shading, ultra-realistic material simulation (glass, metal, plastic), or abstract gradient blob forms. Choose the style that matches your brand's personality.

Color harmony: the 3D object should use your brand's color palette. The background should complement it — typically either very light (off-white) or very dark for maximum contrast with the 3D form.

Apply this to my [product/brand]: [describe what you're building and what the central 3D object should represent — your product, a concept, a symbol]. The result should have immediate visual impact — the 3D element makes the viewer stop and look.
```
