## AI Prompt

Bu tasarım stilini yapay zekayla uygulamak için aşağıdaki prompt'u kopyalayın:

```text
Design a [personal app/memory-keeping/social profile/digital journal] in Scrapbook UI style.

Scrapbook UI is the digital version of a physical memory book — the kind you'd make after a trip, for a friend's birthday, or to document a year of your life. It feels assembled by hand, not designed by software.

The key visual elements: polaroid-style photo frames (white border, slight drop shadow, optional small rotation), sticky notes in various pastel colors, washi tape strips (semi-transparent, patterned) holding things in place at corners, rubber stamp effects (rough edges, single color), paper textures as backgrounds (cream, light tan, subtle grain).

Nothing is perfectly aligned — elements are rotated ±2-5°, slightly overlapping, at different scales. The imperfection is the point. The whole composition should feel like someone carefully laid it out on a table and you're looking down at it.

Typography mixes: a handwriting-style font for personal notes, a typewriter-style font for labels, clean sans-serif for any functional UI text. Multiple type sizes and styles can coexist because scrapbooks naturally mix media.

Apply this to my [app/section/profile]: [describe what the user is documenting or remembering — travels, recipes, personal milestones, friendships, etc.]. The result should make the user feel like they're holding something precious in their hands.
```
