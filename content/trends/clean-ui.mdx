## Tarihsel Köken ve Bağlam

Clean UI, belirli bir yıla ya da tek bir tasarımcıya bağlı bir akım değildir; kurumsal yazılım geliştirmede onlarca yıllık pratiğin damıttığı bir **tasarım metodolojisidir**. Kökleri, IBM'in 1970'lerde oluşturduğu erken kurumsal grafik kimliklerine kadar uzanır; ancak dijital ürün tasarımındaki biçimini Google'ın Material Design, GitHub'un Primer Sistemi ve Atlassian'ın Atlassian Design Sistemi gibi büyük ölçekli sistem çalışmalarının olgunlaşmasıyla aldı.

Clean UI'ın temel öncülü şudur: Veri yoğun, karmaşık iş uygulamalarında görsel gürültü kullanıcı verimliliğini doğrudan düşürür. Bir muhasebe yazılımında, proje panosu veya analitik dashboard'da her ekstra dekoratif öğe; kullanıcının işi anlamak yerine arayüzü anlamak için harcadığı bilişsel enerjiyi artırır. Clean UI, bu enerjiyi sistematik olarak azaltır.

2010'ların ortasında SaaS patlamasıyla birlikte bu metodoloji yazılım endüstrisinin varsayılan kurumsal dili haline geldi. Bugün Notion, Linear, Vercel, Figma gibi popüler araçların arayüzleri Clean UI ilkelerini oldukça kapsamlı biçimde uygular.

## Temel Özellikler

### 1. 8px Tabanlı Aralık Sistemi

Clean UI'ın bel kemiği matematiksel bir boşluk skalasıdır: 4, 8, 12, 16, 24, 32, 48, 64px. Her öğe arasındaki mesafe bu değerlerden biridir; asla rastgele sayılar kullanılmaz. Bu disiplin, tek bir tasarımcının ürettiği bileşenler ile ekibin geri kalanının ürettiklerinin hizasını otomatik olarak korur ve pixel-perfect uyumu kolaylaştırır.

### 2. Nötr Yüzey Hiyerarşisi

Background, surface, overlay ve border için beş ila yedi ton içeren bir gri skalası kullanılır. `#FFFFFF` sayfa arka planı, `#F9FAFB` bölüm yüzeyi, `#F3F4F6` kart arka planı, `#E5E7EB` ince ayırıcı — bu dört değer çoğu dashboard için yeterlidir. Renk derinliği bu nötr sistemden, vurgu rengi ise ölçülü kullanılan tek bir aksiyon tonundan gelir.

### 3. Tipografik Hiyerarşi ve Okuma Kılavuzu

Başlık, alt başlık, gövde, etiket, yardımcı metin — her katman net puntolar ve ağırlıklarla tanımlanır. Inter, DM Sans veya IBM Plex Sans gibi nötr sans-serif fontlar tercih edilir. Satır uzunluğu 65–80 karakter arasında tutularak tarama değil okuma desteklenir.

### 4. İnce Ayırıcılar ve Görünür Sınırlar

Clean UI, içerikleri birbirinden ayırmak için büyük boşlukların yanı sıra `1px` kalınlığında, düşük opasiteli kenarlıklar ve çizgiler kullanır. Bu çizgiler dikkat çekmez; sadece düzeni organize eder. Hücre sınırları, kart çerçeveleri ve bölüm ayırıcıları bu kategoriye girer.

## Kullanım Senaryoları

### Senaryo 1: SaaS Dashboard ve Yönetim Paneli

Kullanıcının günde sekiz saat bakacağı analitik veya proje yönetim arayüzü, Clean UI'ın en kritik kullanım alanıdır. Renk gürültüsü göz yorgunluğuna yol açar; tutarsız aralıklar dikkat dağıtır. 8px grid ve nötr palet, saatlerce kullanımda bile kullanıcının işi görmesini sağlar; arayüzü değil.

### Senaryo 2: Kurumsal Form ve Veri Giriş Ekranları

CRM kayıt formları, muhasebe giriş ekranları, sigorta başvuru formları — bunların tamamında bilgi yoğunluğu kaçınılmazdır. Clean UI, form alanlarını tutarlı 8px aralıkla gruplandırır; ince çizgilerle bölümlere ayırır; koyu arka plan yerine nötr gri üzerinde çalışarak göz yorgunluğunu minimize eder. Kullanıcı hata oranı bu prensiplerin uygulanmasıyla ölçülebilir biçimde azalmaktadır.

## Tailwind CSS ile Uygulama

```tsx
// Clean UI veri tablosu satırı — ince ayırıcı, nötr yüzey
export function CleanTableRow({
  id,
  name,
  status,
  date,
  amount,
}: {
  id: string;
  name: string;
  status: "active" | "pending" | "closed";
  date: string;
  amount: string;
}) {
  const statusStyles = {
    active: "bg-emerald-50 text-emerald-700",
    pending: "bg-amber-50 text-amber-700",
    closed: "bg-gray-100 text-gray-500",
  };

  return (
    // Satır — ince alt çizgi, hover arka plan rengi
    <tr className="border-b border-gray-100 hover:bg-gray-50 transition-colors duration-100">
      <td className="px-4 py-3 text-xs text-gray-400 font-mono">{id}</td>
      <td className="px-4 py-3 text-sm text-gray-900 font-medium">{name}</td>
      <td className="px-4 py-3">
        <span
          className={`inline-flex items-center px-2 py-0.5 rounded text-xs font-medium ${statusStyles[status]}`}
        >
          {status}
        </span>
      </td>
      <td className="px-4 py-3 text-sm text-gray-500">{date}</td>
      <td className="px-4 py-3 text-sm text-gray-900 text-right font-medium">
        {amount}
      </td>
    </tr>
  );
}
```

```tsx
// Clean UI sidebar navigasyon — nötr yüzey, 8px grid, ince ayırıcılar
export function CleanSidebar({ items }: { items: { label: string; href: string; active?: boolean }[] }) {
  return (
    <aside className="w-60 bg-white border-r border-gray-100 h-screen flex flex-col">
      {/* Logo alanı */}
      <div className="h-14 px-5 flex items-center border-b border-gray-100">
        <span className="text-sm font-semibold text-gray-900 tracking-tight">
          Uygulama
        </span>
      </div>

      {/* Navigasyon */}
      <nav className="flex-1 py-3 px-3 space-y-0.5">
        {items.map((item) => (
          <a
            key={item.label}
            href={item.href}
            className={`flex items-center gap-3 px-3 py-2 rounded-md text-sm transition-colors duration-100
              ${
                item.active
                  ? "bg-gray-100 text-gray-900 font-medium"
                  : "text-gray-500 hover:bg-gray-50 hover:text-gray-900"
              }`}
          >
            {item.label}
          </a>
        ))}
      </nav>
    </aside>
  );
}
```

## 8px Grid Aralık Skalası — Referans

| Token      | Değer | Kullanım                            |
| ---------- | ----- | ----------------------------------- |
| `space-1`  | 4px   | İkon-metin arası, mikro aralık      |
| `space-2`  | 8px   | İnput iç dolgu (dikey)              |
| `space-3`  | 12px  | Küçük eleman arası                  |
| `space-4`  | 16px  | İnput iç dolgu (yatay), kart dolgu  |
| `space-6`  | 24px  | Form grubu arası                    |
| `space-8`  | 32px  | Bölüm içi büyük aralık              |
| `space-12` | 48px  | Bölümler arası dikey boşluk         |
| `space-16` | 64px  | Sayfa üst/alt kenar boşluğu         |
