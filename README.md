## 📌 Proje Hakkında

**Design Trends Showcase**, web ve mobil arayüz geliştiricileri, ürün tasarımcıları ve dijital sanatçılar için hazırlanmış yaşayan bir tasarım kütüphanesidir. Bauhaus ve Art Deco gibi klasik kökenlerden günümüzün Bento Grid, Cyberpunk, Frutiger Aero ve Liquid Glass akımlarına kadar **54 farklı tasarım estetiğini** tek çatı altında toplar.

Her bir akım; yalnızca teorik bir açıklamayla bırakılmamış, **birebir o akımı yansıtan interaktif bir React hero önizlemesi**, **Tailwind CSS tabanlı kaynak kodları** ve v0 / ChatGPT / Claude gibi üretken yapay zeka araçlarında kullanılmak üzere optimize edilmiş **prensip tabanlı AI promptları** ile desteklenmiştir.

## ✨ Öne Çıkan Özellikler

- 🖼️ **54 Özgün Tasarım Akımı & Hero Bileşeni**: Her akım için özel kodlanmış, stilin ruhunu yansıtan canlı React önizleme bileşeni.
- 📚 **Derinlemesine MDX İçerik**: Tarihsel kökenler, tasarım ilkeleri, renk/tipografi kuralları ve gerçek dünya kullanım senaryoları.
- ⚡ **Hazır Kod Blokları & Sözdizimi Vurgulama**: `rehype-pretty-code` ve `shiki` destekli renkli kod blokları ve tek tıkla kopyalama desteği.
- 🤖 **Prensip Tabanlı AI Promptları**: Her akım için özel hazırlanmış, tasarım araçlarına ve AI kod üreticilerine doğrudan beslenebilecek detaylı istemler.
- 🔍 **Dinamik Arama ve Kategori Filtreleme**: Anlık çalışan arama çubuğu ve URL ile senkronize (`?category=...`) çalışan 8 farklı kategori filtresi.
- 🌓 **Akıllı Karanlık / Açık Mod (Dark / Light Mode)**: Sistem tercihlerine duyarlı, `localStorage` ile kalıcı temalama altyapısı.
- 🧭 **İlişkili Akımlar & Navigasyon**: İlgili kategorideki akımları otomatik öneren algoritma ve önceki/sonraki akım gezintisi.
- 📱 **Mobil Öncelikli & Erişilebilir (A11y)**: Breadcrumb gezintisi, klavye dostu odak göstergeleri, ARIA etiketleri ve duyarlı responsive grid.

## 🚀 Başlangıç ve Kurulum

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları izleyin:

### Gereksinimler

- [Node.js](https://nodejs.org/) (v18.17 veya üzeri önerilir)
- `npm`, `yarn`, `pnpm` veya `bun`

### Kurulum Adımları

1. **Depoyu klonlayın:**
   ```bash
   git clone https://github.com/hsemihaktas/TrendsWebsite.git
   cd TrendsWebsite
   ```

2. **Bağımlılıkları yükleyin:**
   ```bash
   npm install
   ```

3. **Geliştirme sunucusunu başlatın:**
   ```bash
   npm run dev
   ```

4. Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresine gidin.

## ✍️ Yeni Bir Akım Nasıl Eklenir?

Sisteme yeni bir tasarım akımı eklemek oldukça basittir:

1. **MDX Dosyası Oluşturun:**
   `content/trends/[akım-slug].mdx` yolunda bir dosya açın ve zorunlu frontmatter alanlarını doldurun:
   ```yaml
   ---
   title: "Yeni Akım Başlığı"
   slug: "yeni-akim-slug"
   category: "modern-populer" # lib/categories.ts içindeki geçerli CategoryId'lerden biri
   tags: ["etiket1", "etiket2"]
   description: "Akımı özetleyen kısa ve net açıklama cümlesi."
   publishedAt: "2024-03-01"
   ---

   ## Tarihsel Köken ve Bağlam
   ...

   ## Tailwind CSS Kod Örneği
   ...

   ## AI Prompt
   ...
   ```

2. **Hero Önizleme Bileşenini Kodlayın:**
   `components/hero/[kategori]/[YeniAkim]Hero.tsx` bileşenini oluşturun.

3. **HeroPreview Haritasına Ekleyin:**
   `components/hero/HeroPreview.tsx` dosyası içindeki `HERO_MAP` nesnesine yeni slug ile bileşeni bağlayın:
   ```tsx
   import YeniAkimHero from './[kategori]/[YeniAkim]Hero';

   const HERO_MAP = {
     // ...
     'yeni-akim-slug': YeniAkimHero,
   };
   ```

Sayfa otomatik olarak `generateStaticParams` üzerinden taranacak, ana sayfa kart listesinde ve filtrelerde yerini alacaktır.
